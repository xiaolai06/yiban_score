# 名单剔除验收记录（2026-10-13）

> 历史验收记录；以下结果仅代表当时版本。当前全站及导出均按≥60合格，最新规则和验收见 [PASS_SCORE_60.md](PASS_SCORE_60.md)。

## 交付与边界

- 入口：名单导入卡片内「导入名单 / 剔除名单」切换，不增加侧栏模块。
- 新代码：`server/roster_removal.py`、`web/roster_removal.js`；启动时添加三张最小审计/剔除标记表。
- 固定以选中工作表的 A 列学号精确绑定。姓名、学院、班级不决定删除，不自动补齐学号。
- 上传和预览不删除数据；完整核对 CSV 不截断；确认勾选、输入“确认剔除”和服务端人数/revision核对后才执行。
- 一个事务删除匹配学生基础信息、当前成绩、修改审计及历次成绩导入明细（含合法学号绑定的异常）。名单外人员不变；仅清理本次剔除导致空出的目录。
- 全部合法去重学号（含未匹配）保留最小剔除标记，后续普通名单导入自动跳过；标记不保存姓名/成绩。无在线解除或撤销剔除按钮。
- 被清理人员涉及的历史成绩批次禁止整批撤销。历史批次汇总保留，不作为当前人数。
- 旧备份、原 Excel 不修改；SQLite 删除不等于磁盘级安全擦除。临时清理为尽力执行，数据库已提交的事务不会因清理失败误报为没删除。
- 后端能力字段 `roster_removal_api_version=1`；旧服务缺少能力时阻止操作并提示正常重启，不使用原增量导入接口假装删除。

## 用户附件只读核验

用户提供的私人XLS只在本机做格式、A列文本学号及结构校验；未将附件、真实人员字段或数据统计明细写入公开源码。没有把真实文件提交到剔除接口，也没有对用户数据库执行剔除或其他写请求。私人附件不存在时对应结构测试跳过，不要求公开源码包含附件。

关键覆盖：

- 同名、错误源姓名不影响学号匹配；前导零保持；重复学号只删一次；未匹配只登记剔除学号。
- 非法/空/公式/错误/布尔/科学计数法/非整数/数字精度风险学号整批阻止，A列表头错位不接受。
- 明确确认与确认人数校验、过期、跨站写边界、预览后修改、事务故障完整回滚。
- 并发重复提交、服务重启后相同令牌幂等、剔除标记长期有效。
- 删除当前成绩、全部关联修改记录、成绩历史明细与异常；未删人员状态/分值/版本完全不变；外键完整。
- 整批成绩撤销保护；后续名单重新导入不重建剔除学号；成绩导入不创建该学生。
- 1205人批量删除（超过常见999参数限制），使用临时ID表而非巨大动态IN参数；只清理相关目录，原有无关空目录保留。
- 全量核对表超过25行不截断、CSV公式开头转义；12批剔除记录完整分页保存。
- Chromium真实浏览器1920/1440/1024/768/390/320宽度完成上传→预览→核对表下载→双重确认→删除→成绩搜索消失→再次名单导入跳过；无整页横向溢出、无JS错误。
- 手机端错误A列及旧后端能力保护。

## 全量回归与原版对照

修改中途完整测试运行：**289 passed、13 failed**（随后新增的2项接口边界测试及最终前端/清理细化已在上述252项中复验，没有重新执行整个全量浏览器套件）。

为判定失败来源，通过 `git archive HEAD` 在独立目录提取任务开始前的已提交源码，不复制用户数据库，运行同一全量套件：**260 passed、14 failed**。修改版13项失败在原版全部出现；原版另有一项异常刷新/滚动测试时序失败。没有为剔除任务修改这些既有业务模块或降低断言。

修改版仍未解决的13项：

- `test_populated_directory_layout[320]`：自适应分页后第三条空分行断言未找到。
- `test_scope_checkboxes_and_real_xlsx_downloads[1440/390]`：目录导出按钮点击超时。
- `test_v2_backend_never_silently_exports_the_old_smaller_unqualified_list`：旧版本导出提示断言失败。
- `test_exception_dialog_incremental_records_filters_and_exports[1440/390/320]`：异常列表分值定位器匹配多项，严格选择器失败。
- `test_simplified_shell_and_navigation[1920/1440/1024/768/390/320]`：原断言仍期待“班级 / 学院”，当前产品标题已为“班级”。

因此交付结论为剔除功能及相关定向回归通过，**不是整个项目所有测试通过**。

## 加载方法

在原服务窗口按Ctrl+C停止，重新运行 `start_windows.bat`，浏览器Ctrl+F5。进入「名单导入 → 剔除名单」上传文件并预览，确认全部学号、按需下载一致性备份后，再由用户明确提交。代码开发没有替用户执行真实删除。
