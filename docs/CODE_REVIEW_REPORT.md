## 主要发现与修复

| 优先级 | 发现 | 修复及路径 |
|---|---|---|
| 高 | XML的ASCII DTD检查可被UTF-16/32编码绕过，可能展开实体并改变学号读取结果 | `excel_reader.py`加入编码感知声明检查及禁止doctype的TreeBuilder；不运行实体/外部链接 |
| 高 | 重复ZIP成员或单元格坐标被最后一个值覆盖，学号绑定结果可能与Office显示不一致 | 拒绝重名ZIP和重复坐标；BIFF公式字符串缓存的合法覆盖单独允许 |
| 高 | 不支持的数据库版本在拒绝前已被切换到WAL | `database.py`先核对支持版本，再更改日志模式；拒绝时保留原数据库 |
| 高 | 普通初始化的executescript可能部分安装结构；迁移按分号拆分不能处理触发器 | 结构安装放入单个事务；使用sqlite3.complete_statement拆分，支持触发器及引号内分号 |
| 高 | 旧程序不认识剔除标记，可能重新插入已剔除学号 | 新增数据库INSERT/学号UPDATE触发器；正常导入仍先跳过剔除人员，schema_version保持2 |
| 高 | 只信任revision时，外部编辑未更新revision可能导致按旧预览删除变化后的人员 | 剔除确认事务内复核身份/分值/版本/实际匹配及关联历史行数，变化则409并整批不删除 |
| 高 | 损坏revision可能被CAST成0后继续递增，破坏并发保护 | 严格核对修订号；异常返回数据库错误，写入整体回滚，不静默重置 |
| 中 | 名单导入允许公式缓存分值；空缓存公式、错误、NaN/Infinity可被当成普通空值 | 保留公式/错误单元格元信息，识别异常行，三种分值读取路径均明确拒绝异常 |
| 中 | 同样的三位小数，名单/手动编辑与成绩导入的舍入不同，可能跨过90边界 | 共享Decimal ROUND_HALF_UP两位输入舍入；只作用于新确认输入，不回写旧成绩，导出仍保留已存数值 |
| 中 | JSON中的true可能被转换成学院ID1/版本1，字符串可能被当成强制确认 | JSON索引/ID/版本用StrictInt，操作确认/范围开关用StrictBool；URL查询数字仍正常解析 |
| 中 | 提交已成功，临时源文件被占用或其他预览损坏却使接口报失败 | `staging.py`共享尽力清理，清理错误不抹掉成功结果，重复提交幂等仍有效 |
| 中 | 临时JSON损坏/类型错误/时间异常导致500，分析后源文件内容变化仍被读取 | 临时记录校验及可读400/404/410；读取二进制时复核原SHA-256，变化返回409 |
| 中 | 只检查Content-Length不能限制没有长度头的分块上传 | `request_limits.py`按实际收到的字节计数，超限在解析前中断并返回413；非法长度400 |
| 中 | 总览的多个SELECT及批次count/分页可能混用并发修改前后的结果 | 多查询使用只读事务快照；目录、学生接口返回revision；前端基础读取比对版本、限次重试及丢弃旧请求 |
| 中 | 学生结果缓存用全局统计revision标记，而不是该列表实际revision | 缓存绑定列表自己的revision，列表/基础数据不一致时补读核对，不缓存错版本结果 |
| 中 | 大量学生/取消名单/班级通过巨大IN参数列表，旧SQLite变量上限会导致导出失败 | 临时ID表参数化逐条插入，保持并集、去重及筛选范围；可选expected_revision，页面实际导出会传读取版本 |
| 中 | 跟进页遍历无关历史记录、返回不需要的人员基础字段，增加解析及传输负担 | SQL先按实际在册ID归属和剔除标记筛选异常，正式清单仅读取所需字段；未知归属仍只全校 |
| 中 | 关闭/重新打开跟进页后，旧导出失败可污染新会话；失败后的旧计数不够明确 | 导出有独立序号/取消信号，关闭时取消；请求参数从已读快照取，旧错误不覆盖新会话；旧结果明确标注且禁用导出 |
| 中 | 同一data-action的CSV/Excel/分类按钮共用DOM key，更新时可能转换兄弟节点并错移焦点 | `safe_dom.js`节点身份包含format/kind/operation，保持真实按钮及键盘焦点 |
| 中 | 数据保存成功但随后刷新失败，提示容易被理解为未保存 | 名单/成绩/手动编辑区分已保存和刷新失败，显示核对提示，避免重复操作 |
| 中 | 工作簿保留所有未压缩sheet XML且缺少Excel行数/坏数值保护 | 按班级逐页序列化压缩；超过行数或存在无效已存分值时拒绝生成误导文件，接口返回可读错误 |
| 低 | 旧文件导入顺序、未使用导入、备份时间写法及启动错误提示 | 全仓库Ruff整理；启动器明确check=False、缩小异常捕获、提供数据库启动失败提示 |

## 保留的接口和兼容性

- `directory_api_version=4`、Excel格式版本3、跟进版本1不变；新增 `read_snapshot_api_version=1` 标识本轮读取快照支持。
- `/api/hierarchy`、`/api/students`返回revision；成绩工作簿响应增加X-Data-Revision。旧客户端可忽略新增字段。
- POST `/api/students/export.xlsx`新增可选 `expected_revision`。不传时仍按最新一致快照导出；新版页面会传，数据变化409要求刷新，不静默扩大核对范围。
- 非法JSON字段类型以前可能被隐式转换，现在422；界面和文档中的正确JSON数字/布尔值用法不变。
- `identifier(Cell(bool))`仍抛ValueError，这是用户字段值校验契约，不是函数参数类型错误。TRY004保留明确单行说明，不改成可能逃过行校验捕获的TypeError。
- 数据库附加触发器在下次启动时按事务安装，无需重写学生或成绩；更新前建议保存一致性备份。恢复旧备份/直接删标记属于管理员操作，触发器并不是磁盘权限或安全擦除机制。
