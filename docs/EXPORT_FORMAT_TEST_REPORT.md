## 本次导出说明口径

| 指标 | 计算 |
|---|---|
| 导出人数 | 本文件实际输出的学生数，不是页面当前页/整个数据库人数 |
| 参与人数 | 有效数值得分率 >0（且≤100）；空值/0/其他无有效数值不参与 |
| 未参与人数 | 导出人数−参与人数 |
| 参与率 | 参与人数÷导出人数 |
| 合格人数 | 有效得分率≥90，恰好90计入 |
| 合格率（占参与人数） | 合格人数÷参与人数；分母0显示“—” |
| 合格占导出人数比例 | 合格人数÷导出人数，额外标明不同分母 |

统计按得分率独立判断，不按未开始/进行中/缺考等状态排除。总计相加人数再算比例，不平均班级百分比。比例以数值单元格、两位小数百分比显示。原状态、原分值、0、空值不变；网站原有有效成绩/平均值/严格>90合格及不合格名单规则不变。说明表明确解释了为什么未完成高分可能属于不合格导出却按本说明数值口径参与/达到90。

学生勾选、表头全选后的取消名单、学院/班级并集及不合格筛选均先由原查询确定最终人员集；说明和明细使用同一份最终快照，没有第二次查询猜数。已剔除人员不再位于正式学生集合，自然不进入导出说明。

CSV不能设置字体、居中或多工作表，保留原纯文本导出。文件指定字体但不嵌入/下载字体，查看设备未安装时由Excel/WPS替代。
