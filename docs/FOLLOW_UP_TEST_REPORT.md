# 统一合格口径与辅导员待跟进清单验收（2026-10-14）

> 历史验收记录：下文的90分规则和测试成绩仅代表2026-10-14版本。当前全站及导出均按≥60合格，边界分类为恰好60，最新规则和验收见 [PASS_SCORE_60.md](PASS_SCORE_60.md)。

## 当时规则（现已被60分规则替代）

- 全站、学院总览、成绩明细及Excel：有效数值得分率 **≥90（含90）** 为合格，不因未开始/进行中/缺考等状态排除高分。
- 不合格：无有效数值或<90，现有 `below_90` 参数名保持兼容；`at_90`是qualified的子集，不能再从总数重复扣除。
- 考试进度单独跟进：≥90但未开始/进行中仍需跟进进度，不能称为低分不合格。原状态与分值不改写，暂存数值原样显示并提示未结算。
- 已结算人数及平均值维持原规则：排除空值和未开始/进行中暂存分值，真实完成0保留并参与平均。Excel参与率继续按>0计算，不据此断定实际缺考。
- 能力版本：directory_api_version=4、score_export_workbook_version=3、follow_up_api_version=1。旧后端只读补算≥90统计，规则不同的筛选/导出必须重启；补算失败不伪造0或继续冒用旧合格人数。

## 交付

- `server/grade_rules.py`、`web/grade_values.js`：共享数值资格规则；SQL、Python导出和前端补算一致。
- `server/follow_up.py`、`web/follow_up.js`、`web/follow_up.css`：成绩明细内「待跟进」入口，自定义弹窗、分类、独立搜索、分页、刷新及全量Excel/CSV导出。
- 当前正式分类：未录入、未开始、进行中、已完成/已录入<90、其他低分需核对、恰好90（已合格边界参考）；所有待跟进按在册人员去重，分类可交叉，不能把分类计数直接相加。
- 历史异常核对复用已保存导入异常，不伪造解决/待解决状态，不计入正式在册及待跟进总人数；当前成绩和历史分值分开。在学院/班级范围只按实际在册学号绑定，不猜测名单外或缺失学号的学院班级；未知归属仅在全校查看。已剔除学号排除。
- API清单/计数同一只读事务快照；导出当前分类、搜索及范围的全部页，前端带expected_revision，数据变更返回409要求刷新。Excel沿用字体/居中及文本学号保护，CSV沿用BOM和公式转义。
- 只实现本次要求的规则统一和分类清单，没有催办备注、联系记录或处理状态编辑，不修改真实成绩或人员。
